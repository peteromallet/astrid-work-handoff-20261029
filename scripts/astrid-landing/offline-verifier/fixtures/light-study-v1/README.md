# Light study verifier fixture

This compact fixture preserves the light-study-v1 identities and 8/12/8 second sequence for offline integrity and contract tests. The files in `media/` and `posters/` are short text placeholders with matching SHA-256 entries; they are intentionally not playable media. These tests verify file presence, hashes, paths, and cross-file identities, not audiovisual playback.
