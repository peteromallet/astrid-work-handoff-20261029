Do not infer public output declarations from node output arity. Even independent readback shares some schema resolution: retain explicit hand-authored naming/position expectations.

Extend tests/test_workflow_bundle.py, rather than create another validator: unknown/duplicate/non-finite/malformed companion data, scoped bindings/native ports/presentation references, missing/swapped/same-custody-different-generation pairs, and failure-before-construction. Preserve legacy optional companions and nonpersistent previews.

Publication tests assert validation before replacement, ordinary failure recovery, and mixed-generation refusal during an injected read between replacements. They must not demand simultaneously replaced files or unchanged visible bytes throughout that interval. If rollback fails, assert honest recovery failure rather than successful restoration. ## Preservation rules

- Preserve unique invariants and independent expected results. Share setup/assertion helpers only when their contracts really match; never have the implementation manufacture both expected and actual.
- Different public doors deserve boundary tests even when they share a kernel. Mocked transport tests, real application boundaries with fixture model responses, and live-provider tests prove different claims.
- Keep low-relevance suites in their existing lanes. Defer is not quarantine, skip, deletion, or permission to ignore a failing full-suite test.
- Reuse existing pytest/Node/Playwright, fixtures, test taxonomy and Makefile lanes. No new universal test DSL, catalog service, style framework or broad migration.
- Scope cleanliness checks to supported emitted syntax and complete artifacts, with semantic checks beside them. No adversarial arbitrary-Python analyzer or blanket prohibition on supported edits.

## Retirement evidence

Before merging any deletion or consolidation, record a small mapping in the change evidence: old test/invariant; replacement test/assertion; independent expected result; unique negative/boundary cases retained; targeted defect or minimized historical failure the replacement catches; old/new relevant selection results. Demonstrate defect detection with a bounded targeted perturbation where appropriate, not a repository-wide mutation framework. If evidence is inconclusive, retain the test. Intentional compatibility import paths need a consumer/collection check before removal.
