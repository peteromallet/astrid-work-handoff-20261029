# Retire the `astrid serve` bridge (18 Oct 2026)

**Goal (owner-approved):** the Runtime path (workspace.v1) is the only local data path. The bridge provider and its fakes go. `dev:editor` (instant UI dev, no install) and the timeline e2e suite run against a small seeded fake Runtime built from the two fakes we already have (`runtimeFixture` for timelines, `fakeBridgeRouter` for everything else, the latter held to the recorded real-daemon responses), so dev and tests speak the protocol users get. **Conventions:** `tasks/2026-10-16-plan-a-execution.md` (card format, tiers) and R-1 (every deleted test's useful assertions get a named home), R-7 (a test of deliberately changed behaviour is rewritten, never weakened or just deleted). **The referee is the test run.**

## 1. Shorthand and rules

| Shorthand | Means |
|---|---|
| `U <file>` / `N <file>` | `npx vitest run --config config/testing/vitest.config.ts <file>` / `node --test <file>` passes (a TS server under test: `node --import tsx --test <file>`) |
| `ALL` | `npm test && npm run lint && npm run quality:check` green, and `npx tsc -p tsconfig.app.json --noEmit 2>&1 \| grep -c error` is no higher than the baseline recorded in R0.0 |
| `TL` | `npm run test:e2e:timeline` green, and its `--list` spec and test counts equal the counts recorded in R0.0 (no test lost, none skipped). **No `--update-snapshots`, ever**: a pixel diff against `tests/e2e/visual-snapshots/` or a geometry diff against `tests/e2e/timeline/layout-baseline.json` goes to CP-F with the diff images, and Opus decides |
| `LEFT <names>` | `rg -n '<names>' src tests scripts config docs playwright*.ts package.json eslint.*.js .megaplan -g '!node_modules'` prints nothing |

- **Tiers:** H Haiku (mechanical or bounded, the default), S Sonnet (hard or cross-cutting), O Opus (taste, one design checkpoint, final review). **S reviews only the H cards that delete or rewrite tests: A1a, A1c, D1, D2, D3**, looking specifically for weakened or deleted assertions. Cards with a strict referee (R0.2, F1, E3) are not reviewed. Review passes are not cards. A card that fails twice moves up a tier.
- Allowlists shrink: any entry in `eslint.shared-layer-allowlist.js`, `eslint.strict-debt.js` or `.megaplan/debt.json` that names a deleted file is removed in the card that deletes it.
- **Burn down in the same PR:** a replacement card and the deletion card of its predecessor merge together or in adjacent commits (F3 + D1, A2 + A4+A3).
- No new `*.md`. Docs are edited in D4. Toasts stay errors-only.
- **Merge-order files** (one card at a time): `package.json` (R0.1, A1c, E12, E5, D1), `VideoEditorPage.tsx` (R0.2 then A2), `playwright.config.ts` (E12 only), the three extension configs (E3 only), `scripts/release/verify-extension-ship.test.mjs` (E5 then D1), `scripts/dev-local-workspace.mjs` (R0.1 then A1c).
